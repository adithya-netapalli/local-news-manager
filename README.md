# Local News Manager

AI-powered regional news summaries for readers in Telangana and Andhra Pradesh.

> Work in progress.

Local News Manager fetches news headlines and, when a reader asks, generates a short Telugu summary in the style of the selected region. Every summary is labelled AI-generated and links back to the original publisher.

## Planned features

- Choose a region: Telangana or Andhra Pradesh
- Short Telugu summaries in the regional style
- Summaries are written only when a reader asks, then saved and reused
- Every summary links to the original publisher
